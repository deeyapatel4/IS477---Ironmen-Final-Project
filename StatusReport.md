## 2. Task Updates and Progress

The group has made progress on the project, completing the first four stages outlined in the project plan: data collection, data quality assessment, data cleaning, and data integration. As of November 19, the group is currently working on the analysis stage.

For **data collection**, Jodi and Saint were responsible for gathering and organizing the three datasets from the Art Institute of Chicago's Open Data API: Artworks, Agents, and Exhibitions. They used Python to download 200 records from each dataset and converted the original JSON data into CSV format using pandas. The datasets were then uploaded to the GitHub repository, along with the Python script used to retrieve them.

For **data quality assessment**, Deeya and Rachel reviewed the datasets for missing values, inconsistencies, and potential issues with matching records. Following this assessment, Rachel and Saint worked on **data cleaning**, focusing on addressing missing information, standardizing data formats, and preparing the datasets for integration.

During **data integration**, Deeya and Jodi worked on connecting the three datasets using shared artwork and artist identifiers. This stage focused on identifying relationships between the datasets and addressing potential issues with matching records.

The group is currently in the **analysis stage**, led by Deeya and Saint. This involves examining the integrated data to identify patterns in artist and art-style representation across exhibitions. Once the analysis is completed, the remaining tasks will include creating visualizations, developing a reproducible workflow, completing documentation, and conducting a final review before submission.
